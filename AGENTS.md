# Hinweise für die Arbeit im Repository

- Das Repository ist ein Workshop: Die Starter-App in `src/`
  und die Aufgaben in `exercises/` sind bewusst als Lernschritte angelegt.
  Änderungen sollen Reihenfolge, Zeitrahmen und selbstständige Übungen erhalten.
- `workshop-demo/` ist eine separate, fertige Referenz für die Vorführung.
  Demo-Time-Szenen in `.demo/` dürfen keine Teilnehmerarbeit überschreiben
  oder automatisch zurücksetzen.
- Voraussetzungen, Start und Übungsreihenfolge stehen in `README.md`; die
  Anleitung zur Referenz steht in `workshop-demo/README.md`. Dokumentation bei
  Änderungen am Ablauf oder an den Befehlen mit aktualisieren.
- Anleitungen richten sich vorrangig an Windows mit PowerShell; eine
  macOS-Alternative kann ergänzend angegeben werden.
- Nach Änderungen an Anwendung oder Konfiguration `npm run build` im
  Repository-Root ausführen. Die Referenz wird dabei typgeprüft, aber nur
  über den Vite-Entwicklungsserver unter `/workshop-demo/` bereitgestellt.
- Geheimnisse gehören weder in Frontend-Konfiguration noch ins Repository.
